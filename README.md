# JavaScript Weight Converter
This repo is an adaptation of [Simple Weight Converter App With JavaScript & Bootstrap 4](https://www.youtube.com/watch?v=7l-ZAuU8TXc&list=PLillGF-RfqbbnEGy3ROiLWk7JMCuSyQtX&index=8&pp=iAQB) by Traversy Media. 

I followed the tutorial to learn followings:
- Building a simple weight converter app
- Input weight in pounds
- Output weight in grams, kilograms and ounces
- Design UI with Bootstrap
